# 交互原型说明

## 启动

直接打开 `index.html`，或使用任意本地静态文件服务器启动本目录。原型不依赖网络资源。

## 定位

本原型只作为页面布局、视觉层级和主要操作流程的参考。中央程序化地图不是 Mars3D，也不构成生产实现代码。

实际开发必须遵循 `../plan.md`：Mars3D 是唯一地图引擎；开发期可使用天地图调试，最终交付使用本地 XYZ、Quantized Mesh、矢量瓦片、覆盖瓦片和 GeoJSON。

## 主要流程

1. 在任务库选择或新建任务。
2. 在任务点页添加、导入和编辑任务点。
3. 在参数页设置遮挡模式、覆盖阈值、有效地球半径系数和接收端高度。
4. 在限制区页生成道路候选范围或绘制多边形。
5. 生成升空方案，选择候选点并查看 30km 连续覆盖。

## 原型与开发差异

- 不得复用 `assets/js/terrain-map.js` 作为生产地图实现。
- 道路采样和手绘网格在生产中固定为 25m。
- 原型中的候选抽稀仅为演示，生产上限为 50,000 个唯一地面候选点。
- 暂停续算、结果失效、只读归档、保存失败和危险操作等状态由开发任务和验收测试补齐。
